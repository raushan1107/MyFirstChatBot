# My First Chatbot (Rasa)

My first chatbot, built with the Rasa framework (2020).

## What's inside

- `MyFirstChatBot/` — Rasa project (intents and stories, domain, custom actions in `actions.py`)

## How to use

`pip install rasa`, then `rasa train` and `rasa shell` inside `MyFirstChatBot/`.
